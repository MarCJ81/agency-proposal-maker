개인정보 처리 방침

견적서 스튜디오 · 최종 갱신 2026-11-21

1. 수집하는 개인정보

없습니다. 회원가입·결제가 없고 운영자 서버로 보내는 데이터가 없습니다. 견적서에 적는 고객사·담당자 정보는 이용자가 입력한 값일 뿐, 앱이 따로 수집하지 않습니다.

2. 저장 위치와 항목

작성한 견적서, 프리셋, 브랜드 키트가 브라우저 localStorage에 저장됩니다. 저장하지 않고 인쇄·PDF로만 내보낼 수도 있습니다.

3. 외부 전송

기본 상태에서는 외부 요청이 0건입니다. 이용자가 AI 문구 기능에 Gemini API 키를 넣고 버튼을 눌렀을 때만 Google Generative Language API로 입력한 문구가 전송되며, 키는 브라우저에만 저장됩니다.

4. 쿠키·추적

쿠키를 쓰지 않습니다. 분석 도구·광고 픽셀·외부 트래커를 넣지 않으며, 이용 기록을 수집하지 않습니다.

5. 보관과 삭제

견적서는 목록에서 삭제할 수 있고, 브라우저 사이트 데이터를 지우면 저장된 견적서와 API 키가 함께 삭제됩니다.

6. 제3자 제공

제3자에게 제공하는 데이터가 없습니다. 운영자는 이용자의 데이터를 받지 않으므로 별도 제공·위탁이 없습니다.

7. 문의

이 앱은 정적 파일로 배포되며 운영자에게 개인정보가 전달되지 않습니다. 문의·오류 제보는 배포 페이지에 안내된 연락처나 배포 저장소의 이슈로 남겨 주세요.
