# 견적서 스튜디오 (Proposal Studio)

마케팅 대행사·프리랜서·1인 개발자가 고객에게 **바로 보낼 수 있는 견적서와 프로젝트 제안서**를 1분 안에 만드는 정적 웹앱입니다.
실전 단가 프리셋 5종을 한 번에 불러오고, 수량·단가·할인·VAT를 고치면 **A4 미리보기와 인쇄용 PDF가 즉시** 따라옵니다.
여기에 **카피 심리학 엔진 · 핀터레스트 디자인 엔진 · 내 구독 AI 원클릭 브리지**를 얹어,
문구를 진단·재작성하고, 견적서 디자인을 8종에서 골라 바꾸고, ChatGPT·Claude·Gemini로 초안을 받아 바로 반영합니다.
서버·빌드·회원가입·외부 트래커가 없고, 모든 내용은 브라우저 `localStorage`에만 저장됩니다.

- 미리보기: `preview-upgraded.png` (디자인 8종·맥락 추천), `preview-design-full.png` (전체), `preview-copy.png` (문구 진단), `preview-bridge.png` (AI 브리지), `preview-desktop.png` (1440×900), `preview-mobile.png` (390×844), `preview-mobile-design.png`, `preview-mobile-copy.png`, `preview-pricing.png` (서비스 단가표), `preview-dark.png` (다크 모드), `preview-print.png` · `preview-print-quote.png` (실제 인쇄 PDF 1·2쪽을 렌더링한 이미지)

## 화면

| 탭 | 내용 |
|---|---|
| **빌더** | 왼쪽 편집(문서 설정 · 서비스 패키지 · 공급자 · 수신자 · 견적 항목 · 제안 내용 · 추진 일정 · 조건 · 보낼 준비) / 오른쪽 A4 실시간 미리보기. 중간에 **문서 디자인**·**내 구독 AI 초안** 패널 |
| **문구 진단** | 8대 심리 트리거 진단 · 감점 표현 탐지·안전 교정 · PAS/BAB/AIDA/4U 설득 문구 생성 → 요약·도입에 바로 넣기 |
| **디자인** | 핀터레스트 스타일 8종 갤러리 · 맥락 추천 · 레퍼런스 이미지 팔레트 추출 · 브랜드 스타일 저장/고정 |
| **서비스 단가표** | 실제로 견적이 나가는 5가지 패키지의 항목·범위·기간·확장 금액. `이 패키지로 견적`을 누르면 빌더에 그대로 들어갑니다 |
| **보관함** | 자동 저장 중인 문서, 이름을 붙여 보관한 문서 목록(열기 · 템플릿으로 · JSON · 삭제), JSON 내보내기/불러오기, 새 문서 |

### 문서 구성 3가지

- **제안서 + 견적서** (기본, A4 2쪽): 1쪽 제안서(배경·작업 범위·산출물·제외 범위·3단계 일정·조건) + 2쪽 견적서(당사자·항목 표·합계·일금 한글 금액·결제 일정·서명)
- **견적서만** (1쪽), **제안서만** (1쪽)

### 빌더에서 바로 되는 것

- 항목별 **수량 × 단가 − 항목 할인(%)** → 공급가액, **전체 할인(정률/정액)**, **VAT 10% 포함/별도 토글**
- 마일스톤 3단계 비중(%)에 따라 **계약금·중도금·잔금 금액 자동 배분** (합계는 항상 총액과 일치)
- 견적서 하단 **일금 한글 금액**(예: `일금 구십칠만구천원정`)과 VAT 포함/별도 표기
- 프리셋을 바꾸면 기존 내용이 대체되지만 **토스트의 ‘되돌리기’**로 한 번에 복구
- **보낼 준비 체크 6항목**: 공급자·수신자·항목/금액·작업 범위·일정 비중 100%·결제/유지보수 조건. 플레이스홀더(`○○`, `010-0000-0000`)가 남아 있으면 완료로 보지 않습니다
- 제안서 내용이 1쪽을 넘으면 **자동으로 글자를 줄이고**(fit 2단계), 그래도 넘치면 미리보기에 `분량 초과` 경고를 띄웁니다
- **요약 복사**: 메일·카톡에 붙여넣을 수 있는 텍스트 요약
- `⌘/Ctrl + Enter` 로 현재 문서 저장

## 서비스 단가 프리셋 5종

| # | 패키지 | 기본 구성 금액 | 기간 |
|---|---|---|---|
| 1 | 숏폼 수집기 · 자동화 툴 커스텀 개발 | 890,000원 (89만~150만 원) | 3주 |
| 2 | SNS(스레드 · 인스타) 월간 운영 대행 | 700,000원/월 (60만~90만 원) | 1개월 |
| 3 | 네이버 블로그 SEO 원고 · 채널 관리 | 550,000원/월 (45만~80만 원) | 1개월(원고 8편) |
| 4 | 스마트스토어 상세페이지 · 상품 세팅 | 600,000원 (상품 1개 55만~120만 원) | 2주 |
| 5 | AI 업무 자동화 · 대시보드 구축 | 1,100,000원 (90만~180만 원) | 4주 |

각 프리셋은 항목 단가표, 작업 범위, 산출물, 제외 범위, 3단계 일정(비중 100%), 결제·유지보수·저작권 조건, 확장 시 금액까지 포함합니다.
금액은 **VAT 별도** 기준이며, 불러온 뒤 항목 단가를 고쳐 조정하는 것을 전제로 한 기본값입니다.

## 계산 규칙 (반올림은 모두 원 단위)

```
항목 금액   = round(수량 × 단가)
항목 할인   = round(항목 금액 × 할인율 / 100)
항목 합계   = Σ 항목 금액            (표의 ‘금액’ 열 = 항목 금액 − 항목 할인)
공급가액    = Σ (항목 금액 − 항목 할인)
전체 할인   = 정률: round(공급가액 × % / 100) / 정액: min(입력값, 공급가액)
VAT 별도    = 부가세 round(공급가액_할인후 × 10 / 100), 합계 = 공급가액_할인후 + 부가세
VAT 포함    = 합계 = 공급가액_할인후, 부가세 = round(합계 × 10 / 110), 공급가액 = 합계 − 부가세
```

- 모든 중간값은 정수 원으로 반올림해 화면의 숫자가 그대로 더해지도록 했습니다. (예: 890,000원 VAT 포함 → 809,091 + 80,909 = 890,000)
- 마일스톤 금액은 `round(총액 × 비중 / 비중합계)`로 배분하고 마지막 단계에서 차액을 보정해 **합계가 항상 총액과 일치**합니다. 비중 합계가 100%가 아니면 화면에 경고합니다.
- 견적번호 기본값은 `Q-YYYYMMDD-01`, 유효기간 기본 14일, 작업 시작일은 작성일 +3일입니다.

## 제안 문구 진단 (카피 심리학 엔진)

`engines/copy-psych-engine.js`(공용 엔진과 바이트 동일 사본)를 그대로 씁니다. 서버 호출 없이 브라우저에서 계산합니다.

- **8대 심리 트리거**: 손실 회피 · 구체적 숫자/앵커링 · 호기심 갭 · 인지 반전 · 사회적 증거 · 희소성 · 권위/실측 · 초저마찰 CTA.
  제안서는 구매 페이지가 아니라 `scarcity`·`cta`가 낮게 나오는 것이 정상이라, 앱에서 **제안서 가중치**로 다시 묶습니다(숫자 20 · 권위 18 · 손실 15 · 요청 11 · 호기심/사회 10 · 반전/희소 8, 합 100).
- **감점 표현 탐지**: `최고의`, `다양한`, `저희는 제공합니다`, `매우`, `빠른 배송`, `1위` 같은 추상어·공급자 중심·번역체·모호한 약속·표시광고 위험을 찾아 대안을 보여 줍니다. `안전 교정 적용`은 사실을 새로 만들지 않고 군더더기·공급자 표현만 바꾸며, 토스트에서 바로 되돌릴 수 있습니다.
- **PAS · BAB · AIDA · 4U 생성**: 문서의 제목·요약·배경·산출물에서 대상/문제/결과/근거 기본값을 채우고, 문장을 생성합니다. `요약에 넣기`·`도입 문구로`·`복사` 중 하나로 끝납니다.
- 제안서에 새 필드 두 개가 추가됐습니다: **도입 문구**(`project.pitch`, 400자, 제안서 상단 강조 블록)와 **맺음말**(`project.closing`, 300자, 비우면 기본 문장).

## 문서 디자인 (디자인 레퍼런스 엔진)

`engines/design-ref-engine.js` + `design.js` 어댑터가 A4 종이의 색·타이포·형태를 `--p-*` CSS 변수로 바꿉니다. 미리보기와 PDF가 **같은 테마**로 나옵니다.

- **스튜디오 기본 + 프리셋 8종**: 스위스 타이포 매거진 · 벤토 그리드 SaaS · 크림 에디토리얼 · 다크 네온 임팩트 · 커머스 클린 화이트 · 네오 브루탈리즘 · 미니멀 럭셔리 세리프 · 비비드 팝 카드.
- **맥락 추천**: 고객사·프로젝트·문구·금액에서 업종·목적(제안서)·무드·텍스트 밀도를 읽어 3~4안을 고르고, 왜 골랐는지(업종 적합도, 목적 적합도, AI 기본값 위험 등)를 보여 줍니다. AI 기본값(보라·파랑 + 큰 라운딩 + 소프트 섀도)은 감점됩니다.
- **원클릭 전환**: 카드나 `적용`을 누르면 미리보기·PDF가 즉시 바뀌고, 토스트에서 되돌릴 수 있습니다.
- **레퍼런스 이미지 팔레트**: 고객사/자사 로고·상세페이지·브랜드 컷을 넣으면 5bit 양자화 → 면적·채도·대비 기준으로 배경·서피스·포인트·글자를 뽑고 WCAG AA로 보정합니다. 현재 디자인의 타이포·구조는 유지하고 색만 바꿔 테마로 만듭니다.
- **브랜드 스타일 고정**: 현재 디자인(프리셋 또는 추출 테마)을 이름 붙여 저장하고, `새 문서를 이 브랜드로 시작`을 켜면 새 견적서가 같은 톤으로 열립니다. 문서가 브랜드를 쓰는 동안은 미리보기 pill에 🔒가 붙고, 브랜드를 갱신하면 그 문서도 따라갑니다.
- 다크 네온은 인쇄 잉크가 많이 들고, 네오 브루탈리즘은 금융·B2B에 신뢰도가 떨어져 카드에 경고를 표시합니다.

## 내 구독 AI 원클릭 브리지

`engines/ai-bridge.js`가 ChatGPT · Claude · Gemini 링크와 초안 파싱을 담당합니다.

1. 빌더의 **내 구독 AI로 제안서 초안** 패널이 고객사·프로젝트·기간·기존 문구로 프롬프트를 만듭니다(약 1,500자). 연락처·이메일·사업자번호는 프롬프트에 넣지 않고, 금액은 `금액 포함`을 켤 때만 들어갑니다.
2. `ChatGPT 열기` · `Claude 열기` · `Gemini 열기`를 누르면 **프롬프트를 클립보드에 복사하고 새 창**을 엽니다. 짧은 프롬프트는 `?q=`로 입력창까지 채우고, 제안서 프롬프트처럼 길면(주소 한도) 세 AI 모두 `붙여넣기`로 안내합니다.
3. 받은 답변을 `받은 초안 붙여넣기`에 넣으면 `[요약] [도입] [배경] [작업 범위] [산출물] [제외 범위] [클로징]` 라벨을 읽어 요약·배경·범위·산출물을 나누고, 글자수와 설득 점수를 미리 보여 줍니다. 라벨이 없으면 첫 짧은 문단을 요약, 나머지를 배경으로 나눕니다.
4. `제안서에 적용`을 누르면 문서 필드에 반영되고 토스트에서 되돌릴 수 있습니다.
5. **무료 Gemini API 키(선택)**: 키를 넣으면 새 창 없이 이 화면에서 초안을 받습니다. 키는 이 브라우저(`agency.v1.settings`)에만 저장되고 Google 주소로만 전송됩니다. 키가 비어 있으면 외부 요청을 **한 건도** 보내지 않습니다.

## 인쇄 · PDF

- 화면 미리보기는 실제 **210×297mm** 종이를 그리고, 창 폭에 맞춰 자동 배율(맞춤/±/100%)로 보여 줍니다. 모바일에서는 세로로 2쪽이 이어집니다.
- `인쇄 · PDF` → 브라우저 인쇄 창 → 대상 `PDF로 저장`. `@page { size: A4; margin: 0 }` 이 적용되어 **정확히 210×297mm** 로 출력되고, 편집 화면·상단바·버튼·배경은 인쇄에서 빠집니다.
- 색 배경(브랜드 바, 표 헤더, 강조 금액)은 `print-color-adjust: exact` 로 그대로 인쇄됩니다.
- 다크 모드에서도 종이는 항상 흰 종이로 인쇄됩니다.

## 프라이버시

## 알려진 한계

- 금액은 원(KRW) 단위 정수 계산만 지원합니다. 외화·부가세율 변경(면세 등)은 지원하지 않습니다(VAT 10% 고정).
- 제안서 1쪽 분량을 크게 넘기면 자동 축소 후에도 내용이 잘릴 수 있습니다. 이때 미리보기에 `분량 초과`가 표시되니 문장을 줄이거나 범위 항목을 정리하세요. (인쇄는 항상 A4 2쪽 고정)
- 전자서명·직인 이미지는 넣지 않았습니다. 서명 자리에 `(인)` 표시만 있으며, 실제 직인은 인쇄 후 날인하는 용도입니다.
- 데이터는 브라우저에만 있습니다. 브라우저 데이터를 지우면 사라지므로, 중요한 견적은 `JSON 내보내기`로 보관하세요.
- 프리셋 금액은 시장에서 통하는 기본 구성 예시입니다. 세금계산서·계약 조건은 실제 계약 전에 한 번 더 확인하세요.
- AI 초안과 카피 교정 결과는 **초안**입니다. 숫자·일정·보증을 새로 만들지 않도록 프롬프트와 파서가 막지만, 발송 전에 사람이 한 번 읽어야 합니다(앱도 적용 전에 미리보기를 보여 줍니다).
- ChatGPT·Claude의 주소 자동 입력은 각 서비스가 공식 문서로 보장하지 않는 기능입니다. 제안서 프롬프트는 길어서 실제로는 `붙여넣기`로 안내되는 경우가 많고, 그때도 클립보드 복사는 항상 함께 됩니다.
- 세리프 테마는 기기에 따라 글꼴이 달라집니다(`Noto Serif KR` → `AppleMyungjo` → `바탕` 순). 한글 세리프가 없는 환경에서는 산세리프로 대체됩니다.
- 레퍼런스 이미지에서는 색만 뽑습니다. 레이아웃·폰트는 뽑지 않으므로, 구도를 재현하려면 프리셋을 고르고 색만 추출 테마로 바꾸는 방식이 정확합니다.
